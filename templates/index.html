✓ Clean 7-Feature Cross-City Pipeline
7 Features · Zero Leakage

Input features consist of the 6 criteria pollutants (PM2.5, PM10, NO2, SO2, CO, O3) plus the atmospheric particulate size ratio (PM_ratio). Methodologically redundant features (such as monotonic log transforms under QuantileTransformer, double-counting, and target proxies) have been cleanly eliminated.

Sensor Hardware Deployment Tiers (Reviewer Experiment E9)

Cross-city generalisation under sensor failure and low-cost deployment scenarios. Evaluates transfer performance across four realistic hardware sensor configurations:

Hardware Deployment Tier Sensor Payload Mumbai (Acc / MAE) Lucknow (Acc / MAE) Hyderabad (Acc / MAE)
Tier 1: Full CAAQMS PM2.5, PM10, NO2, SO2, CO, O3, Ratio (7) 99.40% / 4.52 98.56% / 6.59 98.44% / 5.34
Tier 2: Low-Cost Particulate PM2.5, PM10, PM_ratio (3) 95.81% / 4.83 96.77% / 7.84 98.08% / 4.42
Tier 3: Particulate + Combustion PM2.5, PM10, PM_ratio, NO2 (4) 96.41% / 5.13 95.45% / 7.18 98.68% / 5.59
Tier 4: Minimal Particulate PM2.5 only (1) 69.34% / 17.92 70.78% / 24.17 66.47% / 18.43
💡 Key Research Finding: Low-cost particulate-only stations (Tier 2) retain >95.8% accuracy across all cohorts, proving that cross-city transfer can be deployed with ~60% reduction in hardware sensor costs.
